# Geography implementation status

The two curated Street View clues are prepared in the ignored local event bank. Teams answer the country or city aloud. The host judges and uses the ordinary Trivia wrong-answer, award, reveal and finish controls. Street View needs a browser Maps JavaScript API key; no Geocoding API, typed-answer endpoint or automatic answer check is used.

See `trivia-host-flow-refactor-plan.md` for the shared-panel implementation plan and verification matrix.
