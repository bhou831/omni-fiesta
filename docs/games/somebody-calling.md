# Somebody's Calling

All joined players enter for free. Host initiates one uniform random draw among eligible joined players, including temporarily disconnected players; connection state must not change the odds. Persist the selection before acknowledgment. There is no session countdown.

Only the authenticated host receives the selected identity and phone number. The host calls manually; no telephone-service integration is needed. Other phones and TV receive only a waiting state until reveal. Do not make a private selection inferable through the player's balance before reveal: commit the prize award with the public reveal, not at the secret draw.

Host reveal credits the configured 500-token award exactly once and publishes the selected public name/emoji and reward. Never publish the phone number. A retry or restart preserves the selected person and cannot reroll. The final screen then shows the complete ranking of all participants by settled token balance.

Acceptance: draw charges nobody; repeated draw requests preserve one selected player; private draw causes no player-visible balance change; repeated reveal awards once; neither phone nor email appears in display/player payloads; disconnected selected players remain eligible; every player appears in final ranking.
